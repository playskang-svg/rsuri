업로드 페이지 사용법

  

    

      
1정보 입력상호·연락처·채널
→

      
2사진 올리기공사 전/후 · 설명
→

      
3저장입력칸을 벗어나면 자동 저장(정보는 저장 버튼)
→

(매일 05:00)

    

    
입력한 내용이 키워드 사이트 어디에 나오나요?

    

      
상호·대표자·사업자번호·주소·영업시간→모든 페이지 맨 아래(푸터)

      
연락처(전화번호)→상단 전화 버튼 · 하단 고정 바 · 문자 문의 번호

      
카카오톡·인스타그램·블로그·유튜브·스레드·웹사이트→푸터 아이콘 (입력한 것만)

      
디자인 템플릿 선택→사이트의 구성·디자인 전체 (사진 칸 수도 템플릿에 맞춰짐)

      
공사 전/후 사진 (작업 사례)→대표 이미지 · 전후 비교 슬라이더 (전·후 둘 다 올린 사례만, 사례 3은 대표 이미지)

      
사진 설명→사진 아래 글귀

      
지역 선택 + 사진·설명·지역 소개→그 지역 페이지에만 (없으면 공통 사진 사용)

      
카테고리별 사진 · 메모 · 사업자등록증 · 참고 사이트✕사이트에 표시되지 않음 (보관용)
